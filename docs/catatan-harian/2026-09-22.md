# 📝 Catatan Harian Pengembang — 22 September 2026

## 📌 Ringkasan Pengerjaan: Restorasi Web UI Responsif Murni & Optimalisasi Scroll Vertikal (Web-First Approach)
Pada hari ini dilakukan penyesuaian arsitektur dan pengalaman pengguna (UX) mendasar berdasarkan arahan akademik dan evaluasi proyek: **Fokus 100% pada Aplikasi Web Responsif Murni Terlebih Dahulu Sebelum Dikonversi Menjadi Aplikasi Mobile/Native**. 

Seluruh modifikasi *app-kiosk lock* yang sebelumnya dipasang (seperti `overflow: hidden` kaku pada tag `<main>`, bottom sheet tiruan mobile, dan PWA manifest kiosk) telah dibersihkan dan dikembalikan ke antarmuka web standar yang bersih, responsif, dan dapat di-scroll dengan leluasa di seluruh fitur (Admin Panel, Generator Stiker QR Code Meja, Layar Dapur KDS, Master HPP/COGS, dan Kasir POS).

---

## 🎯 1. Latar Belakang & Arahan Kebutuhan Proyek
- **Web-First Mandate**: Proyek METOPEN difokuskan pada luaran platform web responsif modern yang stabil dan fungsional penuh di browser desktop, laptop, tablet, maupun smartphone sebelum melangkah ke tahap konversi aplikasi.
- **Identifikasi Masalah (Bug Diagnosis)**:
  - Pada pengujian di perangkat laptop, tampilan halaman Admin (khususnya fitur **Generator Stiker QR Code Meja**) dan **Pesanan Aktif** terpotong di bagian bawah dan mouse-wheel scrolling terkunci akibat style `overflow: hidden` pada container `<main>`.
  - Percobaan menambahkan PWA kiosk manifest dan layout bottom sheet mobile kaku mengorbankan fungsionalitas scroll desktop/laptop.

---

## 🛠️ 2. Restorasi & Refactoring Antarmuka Pengguna (UI/UX)
- **Restorasi State Bersih (`8c02591`)**:
  - Mengembalikan berkas komponen inti (`DashboardLayout.tsx`, `KasirView.tsx`, `app/globals.css`, `app/layout.tsx`, `app/order/page.tsx`, `app/utils/productUtils.ts`) ke versi stabil web-first.
  - Menghapus berkas `public/manifest.webmanifest` agar browser merender sistem sebagai standar web application modern tanpa memaksakan kiosk mode.
- **Scroll Vertikal Alami (`overflow-y: auto`)**:
  - Mengaktifkan `overflowY: "auto"` pada `<main className="growkas-main-content">` di `DashboardLayout.tsx` sehingga halaman yang memiliki banyak konten (tabel omzet, grid stiker QR meja, form bahan baku) dapat digulirkan secara bebas hingga bagian paling bawah.
  - Menambahkan styling scrollbar elegan modern pada `globals.css` (`::-webkit-scrollbar` dengan aksen warm terracotta `#D4651C` dan track semi-transparan).
- **CSS Responsive Breakpoints Murni**:
  - `@media (max-width: 900px)`: Mengubah tata letak Kasir POS (`growkas-pos-layout`) menjadi stacking 1-kolom fleksibel tanpa penguncian tinggi layar kaku.
  - `@media (max-width: 768px)`: Mengubah layout dashboard (`growkas-layout-wrapper`) agar sidebar berpindah menjadi top navigation bar horizontal scrollable, header fleksibel, dan konten dapat di-scroll alami pada layar smartphone.
