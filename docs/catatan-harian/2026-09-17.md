## 🚀 1. Arsitektur SaaS White-Label & Onboarding Outlet Mandiri
- **Tujuan**: Saat website ini dijual kepada pembeli (*SaaS buyer*), pembeli dapat mendaftarkan outlet milik mereka sendiri secara mandiri tanpa terikat oleh data sampel keras (*hardcoded sample data*).
- **Komponen Utama**:
  - `BranchManagerModal.tsx`: Form modal 1-click untuk pengisian nama outlet, kota, alamat, dan target omzet bulanan.
  - `app/actions/branchActions.ts`: Server Actions untuk menambah, mengambil, dan menghapus outlet dengan integrasi Supabase PostgreSQL DB & fallback *in-memory* berkecepatan tinggi.
  - `AdminView.tsx`: Tab switcher antara **Performa Omzet & Benchmarking** vs **Generator Stiker QR Code Meja**, serta tombol `+ Tambah Outlet Baru`.

---

## 📱 2. Generator & Cetak Stiker QR Code Meja Mandiri
- **Tujuan**: Memungkinkan pemilik usaha mencetak stiker QR Code nomor meja per cabang langsung dari Dashboard Admin.
- **Komponen Utama**:
  - `QRCodeGenerator.tsx`: Generator stiker QR meja berbasis vektor SVG siap cetak (*print-ready CSS media queries*) dengan logo Growkas, identitas resto, dan tautan halaman pemesanan otomatis (`/order?table=04`).
  - Fitur `📋 Salin Link HP` untuk pengujian instant di perangkat mobile tanpa perlu printer fisik.

---

## 🛒 3. Halaman Pemesanan Customer Mobile (`/order?table=XX`)
- **Tujuan**: Memungkinkan pelanggan memindai QR Code di meja, memilih menu & kustomisasi, lalu membayar secara online via QRIS atau kasir tanpa perlu mengantre.
- **Komponen Utama**:
  - `app/order/page.tsx`: Antarmuka mobile-responsive dengan katalog produk per kategori, indikator meja aktif, Pop-Up Customizer Modal (Es, Gula, Add-ons), serta Modal Pembayaran QRIS Instant & Tunai.
